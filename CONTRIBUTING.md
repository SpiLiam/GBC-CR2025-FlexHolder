# Contributing

Contributions welcome — improvements, fixes, variant designs.

## Ways to contribute

- **Bug reports** — wrong footprint, bad clearance, fit issue in specific cartridge revisions → open an Issue
- **Design improvements** — open a Pull Request with modified KiCad files + updated Gerbers
- **Compatibility reports** — tested on a cartridge variant? Open an Issue or PR to update the README
- **Photos** — real-world build photos help everyone. Attach to an Issue or PR

## Rules

1. KiCad source files must be included with any PCB change (no Gerber-only PRs)
2. Modified designs must be licensed under CERN-OHL-S v2 (same as this project)
3. Keep changes focused — one fix or feature per PR

## Tools

- [KiCad](https://www.kicad.org/) (free, open source EDA)
- Gerber viewer: [Tracespace](https://tracespace.io/view/) or KiCad's built-in
